# PCBs
A collection of simple PCBs made for my TER4M0 course.<br /><br />
These projects are meant to be beginner friendly and to be used to help students develop their soldering skills.<br /><br /> 
Whether more PCBs will be added is TBD.

**Dice**:<br />
A simple dice circuit using a 555 timer and binary counter. Includes a seven segment display (common anode) to display the number.<br /><br />
<img width="100%" height="100%" src="https://github.com/NirmitP1/PCBs/blob/main/dice/images/assemble.jpg" />

**Heart**:<br />
A ring oscillator using capacitors and transistors which creates a chasing effect. The LEDs are arranged in the shape of a heart.<br /><br />
<img width="100%" height="100%" src="https://github.com/NirmitP1/PCBs/blob/main/heart/images/assemble.jpg" />

**Police lights**:<br />
An astable vibrator using capacitors and transistors. Uses blue and red LEDs to emulate police lights.<br /><br />
<img width="100%" height="100%" src="https://github.com/NirmitP1/PCBs/blob/main/Police Lights/images/assemble.jpg" />

**Bird**:<br />
A circuit that creates a bird like sound on a button press. Uses two 555 timers, one which modulates the other to create a sweeping effect.<br /><br />
<img width="100%" height="100%" src="https://github.com/NirmitP1/PCBs/blob/main/bird/images/assemble.jpg" />
